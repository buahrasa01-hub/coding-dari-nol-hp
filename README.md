# Coding dari Nol di HP

Belajar coding dari nol pakai HP saja, tanpa laptop — kode latihan dari tutorial YouTube channel **Bu Ah** (@buah2891).

🎬 Tonton tutorialnya: https://www.youtube.com/@buah2891
(cari video "Coding dari Nol di HP")

## Isi repo ini

| File | Isi |
|---|---|
| `kalkulator.py` | Latihan 1 — meminta dua angka, menampilkan hasil penjumlahannya |
| `tebak_angka.py` | Latihan 2 — permainan tebak angka 1–10 dengan petunjuk |
| `daftar_tugas.py` | Latihan 3 — menyimpan dan menampilkan daftar tugas |

## Cara menjalankan

Semua file bisa dijalankan dari browser HP tanpa install apa pun: buka editor Python gratis di browser (misalnya python.org/shell atau Programiz), salin isi file, lalu tekan jalankan. Atau di komputer:

```bash
python3 kalkulator.py
python3 tebak_angka.py
python3 daftar_tugas.py
```

## Yang dipelajari

- `print` — menampilkan sesuatu di layar
- Variabel — menyimpan nilai dalam kotak berlabel
- `input` — meminta masukan dari pengguna
- Kondisi (`if` / `elif` / `else`) — program mengambil keputusan
- Perulangan (`for` / `while`) — mengulang pekerjaan
- Daftar (`list`) — menyimpan banyak isi sekaligus

## Tantangan lanjutan

1. Kalkulator: tambahkan pengurangan, perkalian, dan pembagian.
2. Tebak angka: batasi jadi 5 tebakan saja.
3. Daftar tugas: tambahkan perintah menghapus tugas yang sudah selesai.

## Rencana 6 minggu (dari video)

1. Penghitung uang jajan
2. Pengingat minum
3. Kuis lima soal
4. Pencatat tugas dengan menu
5. Penghitung diskon belanja
6. Gabungkan semuanya jadi satu program menu utama
